# Gustavo Lmo Portfolio

A desktop-inspired personal portfolio built with React, RWM, TypeScript, Vite, and Tailwind CSS.

The interface is powered by [React Window Manager](https://www.npmjs.com/package/@gustavolmo/react-window-manager), a UI framework for building interactive, window-based experiences in React.

## Features

- Draggable, dockable portfolio windows with responsive layouts
- Profile, projects, system status, and contact email form
- Desktop shortcuts for undo/redo actions
- Customizable themes, backgrounds, colours, borders, and typography
- Go backend for health, telemetry and SMTP server

## Run locally

```bash
npm install
npm run dev
```
